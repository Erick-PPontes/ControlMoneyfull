# ControlMoney - Sistema de Gestão Financeira 

Projeto desenvolvido para avaliar a criação de uma API RESTful (Back-end) e o seu consumo através de uma Single Page Application (Front-end).

##  Tecnologias Utilizadas
* **Back-end:** Java, Spring Boot, JPA/Hibernate, Base de Dados H2.
* **Front-end:** Angular 17/18 (Standalone Components), HTML, CSS, TypeScript.
* **Ferramentas:** VS Code, IntelliJ IDEA, Git/GitHub.

##  Funcionalidades (CRUD Completo)
- [x] **Criar:** Cadastro de novas contas financeiras (POST).
- [x] **Ler:** Listagem em tempo real das contas e saldos (GET).
- [x] **Atualizar:** Edição de dados de contas existentes (PUT).
- [x] **Apagar:** Remoção de contas com confirmação (DELETE).
